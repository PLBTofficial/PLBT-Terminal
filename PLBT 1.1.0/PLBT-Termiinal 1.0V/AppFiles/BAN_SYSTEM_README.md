# Система бана по никнейму — инструкция по установке

## Что здесь лежит

```
api/
  _firebaseAdmin.js     ← общий модуль подключения к Firebase (только сервер)
  check-ban.js           ← публичный эндпоинт: регистрация + проверка бана
  admin/
    ban.js                ← забанить (только для тебя, по секретному ключу)
    unban.js               ← разбанить
    list.js                 ← список всех пользователей + активных банов
public/
  admin.html              ← твоя админ-панель (страница /admin.html)
src/
  ban.js                  ← клиентская логика: ID устройства, никнейм, проверка бана
  script.js               ← ЗАМЕНИ этим файлом свой src/script.js (уже с интеграцией)
index.html                 ← ЗАМЕНИ этим файлом свой index.html (уже с новой разметкой)
package.json                ← ЗАМЕНИ (добавлена зависимость firebase-admin)
.env.example                ← ЗАМЕНИ (добавлены новые переменные)
```

Файлы `cotData.js`, `drawings.js`, `trading.js`, `analytics.js`, `chart.js`, `state.js`, `db.js`,
`migrations.js` и всё остальное — **не менялись**, их трогать не нужно.

## Шаг 1. Скопируй файлы в свой проект

Просто перенеси всё из этого архива в соответствующие папки твоего проекта, заменяя старые
`index.html`, `src/script.js`, `package.json`, `.env.example` — и добавляя новые: `src/ban.js`,
папку `api/`, `public/admin.html`.

## Шаг 2. Установи новую зависимость

```
npm install
```

(подтянет `firebase-admin`, который я уже добавил в `package.json`).

## Шаг 3. Включи Firestore в Firebase (если ещё не включён)

Firebase Console → выбери проект → в левом меню **Firestore Database** → **Create database** →
режим **Production** → любой ближайший регион (например `eur3` для Европы).

## Шаг 4. Получи ключ сервисного аккаунта

Firebase Console → шестерёнка рядом с "Project Overview" → **Project settings** →
вкладка **Service accounts** → **Generate new private key**. Скачается `.json` файл.

**Никогда не клади этот файл в репозиторий и не публикуй его.**

## Шаг 5. Настрой переменные окружения

### Локально (для `npm run dev`)
В `.env.local` (создай, если нет):

```
FIREBASE_SERVICE_ACCOUNT={"type":"service_account","project_id":"...", ...}
ADMIN_SECRET=придумай-длинный-случайный-пароль
```

Значение `FIREBASE_SERVICE_ACCOUNT` — это содержимое скачанного JSON-файла, вставленное
**одной строкой** (без переносов).

### На Vercel
Vercel → твой проект → **Settings** → **Environment Variables** → добавь:
- `FIREBASE_SERVICE_ACCOUNT` — вставь тот же JSON целиком
- `ADMIN_SECRET` — тот же пароль, что и локально

Если Vercel ругается на переносы строк в приватном ключе — закодируй весь JSON в base64
(`base64 -w0 serviceAccount.json`) и вставь base64-строку — код в `_firebaseAdmin.js` понимает оба формата.

После добавления переменных — сделай **Redeploy** проекта на Vercel.

## Шаг 6. Закрой прямой доступ к Firestore из браузера

В Firebase Console → Firestore Database → вкладка **Rules** → вставь:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if false;
    }
  }
}
```

Это важно: твой сайт обращается к Firestore только через `/api/*` (сервер), с ключом
сервисного аккаунта. Прямой доступ из браузера должен быть полностью закрыт.

## Как это работает

1. При первом заходе пользователь видит окно "Придумайте никнейм" — вводит ник, он
   сохраняется в его браузере и на сервере (в Firestore, коллекция `plbt_users`),
   вместе со случайным ID устройства и его IP-адресом.
2. При каждом запуске (и раз в 2 минуты, пока вкладка открыта) приложение спрашивает
   сервер: "я забанен?". Если да — сразу показывается полноэкранный блокирующий экран,
   приложение дальше не грузится.
3. Ты банишь/разбаниваешь через страницу **`https://твой-сайт.vercel.app/admin.html`**
   (вводишь `ADMIN_SECRET`, дальше видишь список всех, кто заходил, и можешь банить в один клик).

## Способы блокировки (три уровня)

- **По никнейму** — сработает даже если человек очистит браузер и зайдёт заново, но
  введёт тот же ник.
- **По ID устройства** — сработает даже если он сменит никнейм.
- **По IP-адресу** — сработает для всех, кто заходит с этого адреса, независимо от ника
  и устройства (полезно против обхода через новый браузер/инкогнито на том же компьютере/сети).

Обход всех трёх сразу возможен только сменой IP (например, другая сеть/VPN) **и** очисткой
браузера **и** новым ником одновременно — то есть довольно неудобно для обычного пользователя.

## Свой профиль пользователя

В модалке "Профиль" теперь виден никнейм и ID устройства — попроси пользователя показать
скриншот профиля, если хочешь забанить его точно по ID, а не только по нику.
